# Final Project 1 - Building Web Applications

A responsive static web application covering DevOps, AWS and Networking Commands.

## Files
- `index.html` - main web page
- `style.css` - responsive styling

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository, for example `building-web-applications`.
2. Upload `index.html` and `style.css`.
3. Go to Settings -> Pages.
4. Select `Deploy from a branch`.
5. Select `main` and `/root`.
6. Save.
7. GitHub will provide the public website URL.

The final website URL will normally look like:
https://YOUR-GITHUB-USERNAME.github.io/building-web-applications/
